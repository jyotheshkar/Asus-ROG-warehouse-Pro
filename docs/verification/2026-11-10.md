## Remaining limits

- Full manual GUI usability, accessibility and Windows/macOS behavior were not tested here.
- SQLite is a local application store; these tests do not establish production reliability, deployment, remote coordination or a service-level guarantee.
- Optional ReportLab installation is required for PDF export; the rest of the supported application uses Python's standard library.
- Legacy import is explicit, requires an empty inventory, assigns fresh numeric IDs and imports products only. It does not import historical in-memory orders or logs, and it leaves the source CSV unchanged.
