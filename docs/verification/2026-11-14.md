## Findings and bounded fixes

The baseline suite discovered 28 tests, with three CSV-import errors and three environment-dependent skips. The `csv.Sniffer` sample contained both delimiters and a quoted multiline specification, causing a valid comma or semicolon file to be rejected. Delimiter selection now matches the known required header; record parsing remains CSV-aware. Duplicate headers, wrong record widths and unclosed quotes are rejected before a transaction writes products/events.

SQLite accepts boolean and some numeric-looking values as row identifiers. The domain now checks positive canonical integer IDs before lookup, rejecting booleans, floats, leading-zero strings and out-of-range integers rather than accidentally modifying another entity. ID limits are SQLite's signed 64-bit range, separate from the quantity ceiling.
